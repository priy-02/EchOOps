# EchoOps memory flow

```text
Simulated incident
  → investigate current logs and metrics
  → Hindsight Recall (actual configured bank)
  → compare returned memory text with current symptoms
  → generate a recommendation and explain memory influence
  → simulate action and record SUCCESS / FAILURE
  → retain complete resolved experience through Hindsight
  → similar incident recalls that retained experience
  → adapted strategy avoids repeating the failed action
```

The UI labels synthetic infrastructure/actions as simulated. Missing Hindsight credentials produce an explicit configuration error; there is no in-process memory substitute. Simulator reset does not delete persistent Hindsight memories.
